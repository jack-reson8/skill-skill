SKILL HEALTH CHECK · RUNS IN YOUR BROWSER

Will your agent actually load this skill?

Agents pick a skill from its description alone. Paste a SKILL.md, or link a skill folder on GitHub, and get a 0–100 score against the Agent Skills spec. Nothing is uploaded; GitHub links are read straight from GitHub.

Linking the folder also checks for reference files nothing points to and paths that don't exist.

What it checks

Name is lowercase-hyphen and matches the folder · description exists, stays under 1,024 characters and says when to use the skill · steps produce or check something · not too many ALL-CAPS commands · body under 500 lines · with a folder link: no orphan reference files, no dangling paths. Each blocking issue costs 15 points, each warning 5. Same rules as skill_audit.py in skill-skill.
